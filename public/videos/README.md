# Video files

The four original silent video files from the Figma design use these project names:

- `mouse.mp4`
- `cables.mp4`
- `circuit-board.mp4`
- `bulb.mp4`

The page detects each file automatically and plays it with `autoplay`, `muted`, `loop`, and `playsinline`. If a file is missing, the matching Figma-exported artwork is shown as a fallback.
