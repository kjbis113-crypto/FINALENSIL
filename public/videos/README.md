# Video files

The main gallery keeps its original four video views:

- `mouse.mp4`
- `cables.mp4`
- `circuit-board.mp4`
- `bulb.mp4`

The supplied `NO1.mp4` through `NO4.mp4` files are retained as visual references. The interactive detail routes render the corresponding OBJ models from `public/models/` as GPU-simulated point clouds.
