# ENSIL 전시 설치 매뉴얼 — 아이맥(웹) + 맥미니(빔프로젝터)

순정 아이맥 기준. **1부는 인터넷 되는 곳에서 미리**, 2부는 전시장에서.
목업 허브 와이파이(`ARCHIVE`)에는 인터넷이 없으니, 1부를 건너뛰고 현장에 가면 아무것도 설치할 수 없다.

역할:

| 기기 | 하는 일 | 필요한 것 |
|---|---|---|
| 아이맥 | 관람객용 웹(갤러리·필드1·아카이브) + 브릿지 서버 | Chrome, Node, 이 저장소 |
| 맥미니 | 빔프로젝터 화면(필드2, `stage.html`) | Chrome 뿐 |
| 목업 ESP32 ×3 + 허브 | 허브가 `ARCHIVE` 와이파이를 띄우고, 목업 셋은 각자 작은 HTTP 서버로 붙는다 (`192.168.4.11 / .12 / .13`) | 전원 |

---

## 1부 — 인터넷 되는 곳에서 미리 (30분)

### 1. macOS 버전 확인
 메뉴 → **이 Mac에 관하여** → macOS 버전을 적어둔다.
- **macOS 11 (Big Sur) 이상**이면 그대로 진행.
- **10.15 이하**면 최신 Node·Chrome 이 설치되지 않는다. → 맨 아래 **[구형 아이맥일 때]** 로.

### 2. Chrome 설치
Safari 로 https://www.google.com/chrome → 다운로드 → dmg 열고 Chrome 을 응용 프로그램 폴더로 끌어넣기.
- 처음 실행 시 "기본 브라우저로 설정" → **설정** (START 스크립트가 브라우저를 자동으로 열 때 Chrome 이 뜨게).
- 구글 로그인 창은 **건너뛰기**.

### 3. Node 설치
Safari 로 https://nodejs.org → 초록 **LTS** 버튼 → `.pkg` 다운로드 → 더블클릭 → 계속·동의·설치 (관리자 비밀번호).
- 설치가 "이 macOS 에서는 설치할 수 없음" 이라고 거부하면 → https://nodejs.org/en/download 에서 **v22** 를 골라 다시. 그것도 안 되면 **[구형 아이맥일 때]**.

확인: **터미널** 을 연다 (Launchpad → 기타 → 터미널, 또는 Spotlight 에서 "터미널") → 아래를 입력하고 엔터.
```
node -v
```
`v22.x` 또는 `v24.x` 가 찍히면 OK. `command not found` 면 터미널을 **완전히 닫고 새로 열어서** 다시.

### 4. 저장소 내려받기
Safari 로 https://github.com/kjbis113-crypto/FINALENSIL → 초록 **Code** 버튼 → **Download ZIP**.
- 다운로드 폴더의 `FINALENSIL-main.zip` 더블클릭 → `FINALENSIL-main` 폴더가 생긴다.
- 그 폴더를 **데스크탑으로** 옮긴다. (경로가 `~/Desktop/FINALENSIL-main` 이 되게)

### 5. 최초 세팅 — `SETUP-MAC.command`
`FINALENSIL-main` 폴더에서 **`SETUP-MAC.command`** 를 더블클릭.

macOS 가 막을 때 (거의 확실히 막는다):
- **"확인되지 않은 개발자"** 경고 → 파일을 **우클릭 → 열기 → 열기**.
- 그래도 안 열리면(macOS 15 Sequoia 이상) → **시스템 설정 → 개인정보 보호 및 보안** → 아래로 내려 **"그래도 열기"** → 다시 더블클릭.
- 더블클릭했는데 **텍스트 편집기로 열리면** 실행 권한이 빠진 것. 터미널에 아래를 붙여넣고 엔터:
  ```
  cd ~/Desktop/FINALENSIL-main && chmod +x *.command && bash SETUP-MAC.command
  ```

터미널이 열리고 몇 분 동안 의존성 설치 → 빌드 → 브릿지 설치가 돈다. **`== 완료 ==`** 가 뜨면 끝. 엔터로 닫는다.
- 중간에 빨간 글씨로 멈추면 대부분 인터넷 문제 — 와이파이 확인 후 다시 더블클릭.

### 6. 한 번 돌려보기 — `START-MAC.command`
`START-MAC.command` 더블클릭 (같은 방식으로 우클릭 → 열기).
- 터미널에 주소들이 찍히고 Chrome 이 `http://localhost:8080/` 을 연다.
- macOS 방화벽이 **"node 가 들어오는 네트워크 연결을 허용하겠습니까?"** 하고 물으면 반드시 **허용**. (맥미니와 목업이 들어오는 문이다. 지금 허용해두면 현장에서 안 묻는다.)
- 갤러리가 뜨고, 상단 **FIELD** 를 누르면 필드가 뜨는지 본다. 개체 4마리가 점 구름으로 뜨기까지 10초쯤 걸릴 수 있다.
- 확인했으면 **터미널 창을 닫는다** (= 서버 종료).

### 7. 아이맥 시스템 설정 (전시 중 꺼지지 않게)
**시스템 설정** 에서:
- **잠자기·화면보호기** → 디스플레이 끄기 **안 함**, 화면 보호기 **안 함** (잠금 화면 항목).
- **배터리/에너지** → 자동 잠자기 방지 켬.
- **알림** → **방해금지(집중 모드)** 켬.
- **일반 → 소프트웨어 업데이트** → 자동 업데이트 **끔**.
- Chrome: 종료 후 다시 열었을 때 "페이지 복원" 팝업은 무시하고 그냥 주소를 친다.

### 8. 맥미니도 미리
맥미니에는 **Chrome 만** 있으면 된다. 2번과 같이 설치. Node·저장소 필요 없음.
맥미니도 7번과 같이 잠자기·화면보호기 끔.

## 2부 — 전시장에서 (매일 아침)

### 1. 전원 순서
1. **허브 ESP32** (`ARCHIVE` 와이파이를 띄우는 보드) 먼저.
2. 아이맥, 맥미니, 빔프로젝터.
3. 목업 셋은 **맨 나중에** (브릿지가 뜬 뒤에 붙어야 한다).

### 2. 아이맥 네트워크 — `ARCHIVE` 에 붙고 고정 IP
목업 셋이 `192.168.4.11 / .12 / .13`, 허브가 `.1` 을 쓴다. 아이맥은 **`192.168.4.100`** 으로 고정해 두면 맥미니가 칠 주소가 매일 같다.

메뉴 막대 와이파이 → **`ARCHIVE`** 접속 (암호 `12345678`). 대문자다.
→ **시스템 설정 → Wi-Fi** → `archive` 옆 **세부사항…** → **TCP/IP** 탭 → IPv4 구성 **수동**:

| 항목 | 값 |
|---|---|
| IP 주소 | `192.168.4.100` |
| 서브넷 마스크 | `255.255.255.0` |
| 라우터 | `192.168.4.1` |

→ 확인. **"인터넷 연결 없음"** 표시는 정상이다.
같은 창에서 학교/전시장 와이파이는 **자동 연결 끔** (macOS 가 인터넷 되는 쪽으로 몰래 갈아타는 걸 막는다).

> 목업을 안 쓰는 날이면 이 단계는 생략. 아이맥과 맥미니가 **같은 와이파이**에만 있으면 된다.

### 3. 아이맥 — 서버 켜기
`~/Desktop/FINALENSIL-main/START-MAC.command` 더블클릭.

터미널에 이렇게 찍힌다:
```
  이 기기         http://localhost:8080/
  다른 기기       http://192.168.4.100:8080/
  필드1 (웹)      /
  필드2 (빔프)    /stage.html
ws://0.0.0.0:7777 대기 중
```
- **이 터미널 창은 닫지 않는다.** 닫으면 사이트와 릴레이가 같이 꺼진다. Dock 으로 내려두면 된다.
- Chrome 이 `http://localhost:8080/` 을 자동으로 연다. 안 열리면 직접 친다.
- Chrome 전체화면: **control + command + F**. (나가기도 같은 키)

### 4. 맥미니 — 빔프로젝터 화면
맥미니도 **`ARCHIVE`** 와이파이에 붙인다 (IP 는 자동으로 받음, 설정 필요 없음).
Chrome 을 열고 주소창에:
```
http://192.168.4.100:8080/stage.html
```
- 필드가 뜨면 **화면을 한 번 클릭** → 전체화면. (또는 **F** 키)
- 우상단에 **● CONSOLE LINKED** 가 초록으로 켜지면 아이맥과 연결된 것. 회색 **CONSOLE WAITING** 이면 아직 못 붙은 것 → 아래 문제 해결.
- 카메라는 약 3분에 한 바퀴 저절로 돈다. 마우스 만질 일 없음.

### 5. 리허설 체크 (2분)
- [ ] 아이맥 필드(`/field.html`) 좌하단 **● STAGE LINKED** 초록
- [ ] 맥미니 우상단 **● CONSOLE LINKED** 초록
- [ ] 아이맥 필드에서 개체에 마우스를 올리면 우하단에 `NO.0x` 판독이 뜨고, **클릭하면 빔프 화면이 한 번 번쩍**
- [ ] 아이맥 필드에서 마우스를 움직이면 커서 뒤로 **초록 유체**가 흐르고, **빔프 화면에도 같은 초록 유체가 따라온다**. 개체 위에 커서를 멈추면 양쪽 모두 그 개체 위에 고인다. (빔프는 카메라 각도가 달라 화면 위치는 다르고, "어느 개체 위인지"가 같다)
- [ ] 목업 셋을 켜면 아이맥 터미널에 `목업 unit 1 ... 접속 (192.168.4.11)` 같은 줄이 세 개 뜬다
- [ ] 아이맥 필드에서 개체를 **클릭하면 그 목업이 움직인다** (NO.1 네오픽셀 · NO.2 텐돈 · NO.3 바다나비. NO.4 는 목업 없음)
- [ ] 목업을 **손으로 건드리면** 아이맥 필드와 빔프에서 그 개체의 파티클이 흐트러지고, 필드 우하단에 판독이 잠깐 뜬다. **페이지는 넘어가지 않는다** — 개체가 쉽게, 동시에 움직여서 화면을 빼앗지 않도록 한 것. 같은 목업은 6초에 한 번만 받는다

### 6. 끝낼 때
아이맥 터미널 창을 닫는다 (또는 control + C). 허브 보드는 마지막에 끈다.

## 문제가 생기면

**`node -v` 가 안 됨** — 터미널을 완전히 종료(⌘Q)하고 새로 연다. 설치 직후엔 옛 창이 못 본다.

**`.command` 더블클릭이 아무것도 안 함 / 텍스트로 열림** — 터미널에서:
```
cd ~/Desktop/FINALENSIL-main && chmod +x *.command && bash START-MAC.command
```

**START 가 "dist/ 가 없습니다"** — SETUP 을 안 돌린 것. 인터넷 있는 곳에서 SETUP 먼저.

**START 가 포트 에러(EADDRINUSE)** — 이미 하나 돌고 있다. 열려 있는 다른 터미널 창을 찾아 닫고 다시.

**맥미니가 페이지 자체를 못 연다** — 네트워크. 둘 다 `archive`(또는 같은 와이파이)인지, 아이맥 IP 가 `192.168.4.100` 인지 확인. 아이맥 터미널의 "다른 기기" 줄에 찍힌 주소를 그대로 친다.

**페이지는 열리는데 CONSOLE WAITING 그대로** — 7777 포트가 막힌 것. 아이맥 **시스템 설정 → 네트워크 → 방화벽 → 옵션** 에서 `node` 가 **들어오는 연결 허용** 인지 확인. 확실치 않으면 방화벽을 잠시 끈다.

**빔프에 초록 유체가 안 따라옴** — 우상단 **CONSOLE LINKED** 가 초록인지 먼저(아니면 위 항목). 링크는 되는데 유체만 없으면 그 맥의 WebGL2 가 half-float 렌더 타깃(EXT_color_buffer_float)을 못 쓰는 것 — 유체만 조용히 꺼지고 필드는 그대로 돈다.

**필드가 흰 화면 / 개체가 안 뜸** — 10초 이상 기다려본다(개체 4마리 생성). 계속 안 뜨면 Chrome 주소창에 `chrome://gpu` → WebGL2 가 "Hardware accelerated" 인지 본다. 아니면 그 맥은 못 돌린다.

**아이맥이 버벅임** — 주소 뒤에 `?quality=low` 를 붙인다 (예: `http://localhost:8080/field.html?quality=low`). 그래도 무거우면 `src/field/particle-creature.js` 의 `FIELD_PARTICLE_TEXTURE_SIZE` 를 `192 → 160` 으로 낮추고 터미널에서 `cd ~/Desktop/FINALENSIL-main && pnpm build` (인터넷 없어도 됨) 후 START 다시.

**빔프 화면이 옆으로 밀려 있거나 잘림** — 맥미니 **시스템 설정 → 디스플레이** 에서 해상도를 프로젝터 기본값(보통 1920×1080)으로. 브라우저는 전체화면(F)인지 확인.

**Ctrl+Alt+Shift+O 는?** — 아이맥 한 대로 빔프까지 걸 때 쓰는 단축키(팝업으로 스테이지 창을 열어 옆 화면으로 보냄). 맥미니를 따로 쓰는 지금 구성에선 필요 없다.

**목업이 반응 없음 / 터미널에 접속 줄이 안 뜸** — 아이맥이 `ARCHIVE` 에 붙어 있는지 먼저. 그 다음 Chrome 에서 `http://192.168.4.11/` (12, 13) 을 직접 열어본다 — 목업 자기 페이지가 뜨면 목업은 살아 있는 것. 목업 IP 가 다르면 START 대신 터미널에서 `node bridge/index.js --mockups 새IP1,새IP2,새IP3` 로 띄우고, 필드는 주소 뒤에 `?mockups=새IP1,새IP2,새IP3` 을 한 번 붙인다(기억됨).

**개체가 스스로 움직였다고 페이지가 넘어가게 하고 싶다** — `src/field-page.js` 의 `ATTRACT_NAVIGATION` 을 `true` 로. 관람객이 30초 이상 아무것도 안 만지고, 같은 목업이 5초 안에 두 번 움직였을 때만 그 개체의 아카이브로 간다. 빌드(`pnpm build`) 후 START 다시.

## 구형 아이맥일 때 (Node 나 Chrome 이 안 깔릴 때)

역할을 바꾼다: **맥미니가 서버**, 아이맥은 화면만.

1. 1부 2~7 을 **맥미니**에서 한다 (Chrome + Node + 저장소 + SETUP).
2. 현장에서 **맥미니**가 `archive` 에 붙어 `192.168.4.100` 고정 IP 를 잡고 START 를 돌린다. (2부 2·3 을 맥미니에서)
3. 맥미니 Chrome 은 `http://localhost:8080/stage.html` 을 열어 전체화면.
4. 아이맥은 Chrome(또는 최신 Safari) 으로 `http://192.168.4.100:8080/` 을 열어 전체화면.

맥미니 화면이 빔프뿐이라 설정이 불편하니, 1부는 **맥미니에 모니터를 하나 물려서** 미리 해두는 게 낫다.
