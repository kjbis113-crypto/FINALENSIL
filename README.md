# FINALENSIL

Responsive main-page implementation based on the provided Figma frame.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

## Media

The four source MP4 files are stored in `public/videos/` using the names documented in [`public/videos/README.md`](public/videos/README.md). Each video autoplays silently, loops continuously, and uses the matching Figma artwork as its poster and fallback.
